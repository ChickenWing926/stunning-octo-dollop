# ⏱️ Timer App

A beautiful, modern timer application with countdown timer and stopwatch functionality.

## Features

### Countdown Timer
- ⏰ Set custom hours, minutes, and seconds
- 🚀 Quick timer buttons (5, 10, 15, 30 minutes)
- 📊 Visual progress bar
- 🔔 Audio notification when timer completes
- 💻 Browser notifications support
- ⏸️ Pause and resume functionality

### Stopwatch
- ⏱️ High-precision timing (centiseconds)
- 🏁 Lap time recording
- ⏸️ Pause and resume functionality
- 📝 Lap history with timestamps

## How to Use

1. **Open the app**: Simply open `index.html` in any modern web browser
2. **Choose mode**: Click either "Countdown Timer" or "Stopwatch" at the top
3. **Countdown Timer**:
   - Enter hours, minutes, and seconds, or use quick timer buttons
   - Click "Start" to begin the countdown
   - Click "Pause" to pause, "Reset" to clear
4. **Stopwatch**:
   - Click "Start" to begin timing
   - Click "Lap" to record lap times
   - Click "Pause" to stop, "Reset" to clear all
